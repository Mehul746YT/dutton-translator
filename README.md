# Dutton Translator

Official website and universal translation suite by **Dutton & Co.**

![Dutton Translator Logo](logo.jpg)

## Features

- **Heritage Dutton Brand & Fixed Theme**: Built with Dutton's signature dark luxury styling (`#121212`, `#181818`, `--dutton-gold #c8933b`), typography with Bitter & Inter fonts, and the distressed gold Dutton 'D' emblem.
- **Full Punjabi Translation Engine (ਪੰਜਾਬੀ)**: Native Gurmukhi and Shahmukhi support, prioritized in the quick switcher and default target language.
- **130+ World Languages**: Comprehensive coverage with instant search, auto-detection, and bidirectional translation.
- **Voice Capabilities**:
  - **Speech-to-Text (Microphone Dictation)**: Real-time voice recognition matching the active language dialect.
  - **Text-to-Speech (Voice Pronunciation)**: Natural pronunciation for translations with speed controls (0.8x, 1.0x, 1.2x) and visual audio wave equalizer.
  - **Two-Way Voice Intercom Mode**: Live conversational translation (e.g. English <-> Punjabi) for fluid spoken dialogue.
- **Heritage Punjabi Vault**: Curated business, greetings, ranch, and travel phrases with 1-click audio playback.
- **Translation History & Favorites**: Local storage persistence for recent queries and quick reuse.
- **Power Features**: Keyboard shortcuts (`Ctrl+Enter`, `Ctrl+Shift+S`, `Esc`), 1-click copy, share modal, and presentation focus view.

## Quick Start

Open `index.html` directly in any modern web browser, or serve it with:

```bash
# Python
python -m http.server 8080

# Or Node npx serve
npx serve .
```

Navigate to `http://localhost:8080`.
